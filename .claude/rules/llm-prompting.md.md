# LLM呼び出しルール

## プロンプト設計
- システムプロンプトとユーザープロンプトを明確に分離
- 出力フォーマット（JSON等）を必ず指定
- 「JSONのみ出力、説明文不要」を明記
- 失敗時のフォールバックを設計

## モデル選択基準
- 複雑な推論が必要 → Sonnet 4.6
- 単純な分類・抽出 → Haiku 4.5
- JSON出力が確実に必要 → Sonnet 4.6（精度高い）

## レート制限対策
- Sonnet: 各呼び出し間に1秒sleep
- Haiku: 各呼び出し間に0.5秒sleep
- 連続失敗3回でabort
